# 放置天地｜GitHub Pages 網頁版

此倉庫專門用來準備「放置天地」的瀏覽器公開遊玩版本。

## 部署原則

- 保留原本可正常遊玩的 Windows 離線版本，不覆蓋、不修改。
- 網頁版在獨立分支開發，確認可用後才發布。
- GitHub Pages 只提供靜態檔案；不把本機 Node.js 啟動伺服器當成線上後端。
- 玩家存檔預設保存在各自瀏覽器的本機儲存空間，不會自動跨裝置同步。
